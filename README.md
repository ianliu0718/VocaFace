# VocaFace 🎤

語音捏臉小遊戲 - 用你的聲音創造獨特的 3D 人像

## 簡介

VocaFace 是一個創新的網頁互動遊戲，透過分析使用者的聲音特徵（音高、音量、語調變化），自動生成一個符合該聲音感覺的 3D 風格人像。

## 功能特色

- 🎙️ **即時聲音錄製**：使用 Web Audio API 進行高品質音訊擷取
- 📊 **聲音特徵分析**：
  - 音高（Pitch）：分析聲音的頻率特性
  - 音量（Volume）：測量聲音的響度
  - 語調變化（Tone Variation）：計算聲音的動態範圍
- 🎨 **智能映射系統**：將聲音特徵對應到視覺特徵
  - 低音 → 成熟、稜角分明的臉型
  - 高音 → 柔和、圓潤的臉型
  - 大音量 → 誇張、表情豐富的特徵
  - 小音量 → 細膩、溫和的特徵
  - 語調變化大 → 複雜、多樣的髮型與細節
- 🖼️ **3D 風格人像生成**：使用 Canvas 繪製具有立體感的人像
- 💾 **圖片下載**：可將生成的人像保存為 PNG 圖片

## 技術架構

### 前端技術
- **HTML5**：結構化的網頁內容
- **CSS3**：漸層、動畫、響應式設計
- **JavaScript (ES6+)**：模組化的程式架構

### 核心模組

#### 1. VoiceAnalyzer（聲音分析器）
- 使用 Web Audio API 進行音訊處理
- 實時頻譜分析和波形可視化
- 計算音高、音量、語調變化等特徵

#### 2. AvatarGenerator（人像生成器）
- 基於 Canvas 2D API 的圖形繪製
- 參數化的臉部特徵系統
- 3D 風格的著色和陰影效果

#### 3. VocaFaceApp（主應用程式）
- 協調各模組之間的交互
- 使用者介面邏輯處理
- 狀態管理和事件處理

## 使用方法

1. **開啟應用**：在瀏覽器中打開 `index.html`
2. **開始錄音**：點擊「開始錄音」按鈕，允許麥克風權限
3. **說話**：對著麥克風說話 3-5 秒鐘
4. **停止錄音**：點擊「停止錄音」按鈕
5. **查看分析**：系統會顯示你的聲音特徵分數
6. **生成人像**：點擊「生成人像」按鈕
7. **下載圖片**：如果滿意，可以下載你的專屬人像

## 系統要求

- 現代瀏覽器（Chrome、Firefox、Safari、Edge）
- 支援 Web Audio API 和 Canvas API
- 麥克風設備和權限

## 聲音特徵對應規則

### 音高 (Pitch)
- **0-40 (低沉)**：較窄的臉型、成熟的五官、深色調
- **40-60 (中等)**：平衡的臉型和五官
- **60-100 (明亮)**：圓潤的臉型、大眼睛、柔和色調

### 音量 (Volume)
- **0-40 (輕柔)**：小眼睛、窄嘴型、細膩特徵
- **40-60 (適中)**：標準尺寸的特徵
- **60-100 (響亮)**：大眼睛、寬嘴型、誇張表情

### 語調變化 (Tone Variation)
- **0-40 (平穩)**：簡單髮型、單色配色
- **40-60 (變化適中)**：中等複雜度的細節
- **60-100 (富變化)**：複雜髮型、豐富的紋理和細節
